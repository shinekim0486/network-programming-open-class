■ 오늘의 규칙

  1. AI가 만든 화면은 초안이다. 검증하기 전에는 제출물이 아니다.
  2. 설계 카드를 쓰고 교사 확인을 받기 전에는 안티그래비티를 실행하지 않는다.
  3. API 키는 코드에 직접 쓰지 않고, 밖으로 내보내지 않으며, 수업이 끝나면 반납한다.
  4. 이름·연락처 등 개인정보는 AI 도구에 입력하지 않는다.

1단계 · 만들기

첨부한 자료로 강동구 공공와이파이 현황 대시보드를 HTML 한 파일로 만들어 줘. [자료] - 설치현황 : JSON 파일. DATA 배열 안에 AP가 1건씩 들어 있다. - 사용량 : CSV 파일. 자치구가 '강동구'인 행만 쓴다. - 두 자료는 [ 공통 칸 이름 ] 으로 연결한다. [만들 것] - 보여줄 것 : [설계 카드 ①] - 쓸 컬럼 : [설계 카드 ②] - 화면 형태 : [설계 카드 ③] - 지도를 쓸 경우 Google Maps를 쓰고, API 키는 코드 맨 위 설정 변수 한 곳에만 둔다. 만들기 전에 무엇을 할 것인지 먼저 알려 줘.
★ 보내기 전 확인: ① 자료를 첨부했나 ② 압축을 풀어 필요한 CSV 하나만 올렸나
★ AI가 보여주는 작업 계획을 읽고 승인한다. 읽지 않고 누르지 않는다.

검증 숫자가 맞는지 대조한다

AI는 틀린 숫자도 자신 있게 보여준다. 맞는지 확인하는 건 사람의 일이다.

3단계 · 검증 질문

질문 세 개에 답해 줘. 코드는 고치지 말고 답만 해. 1. 이 화면에 전체 AP가 몇 개로 나와 있어? 설치현황 JSON의 DATA 건수와 같아? 2. 두 자료를 이었을 때 사용량이 붙은 AP는 몇 개야? 사용량 자료가 없는 AP는 어떻게 처리했어? 0으로 채웠어, 아니면 뺐어? 3. 그렇게 처리했을 때 화면이 사실과 달라지는 부분이 있어?

4단계 · 바로잡기

★ □ 안에는 내가 직접 센 숫자를 넣는다. 이 한 줄이 없으면 이 대시보드는 거짓말을 한다.
